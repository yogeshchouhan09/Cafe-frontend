# Ember & Bean — React Café Seat Booking

A responsive frontend-only café website built with React + Vite.

## Features
- Responsive café landing page
- Seat reservation floor plan
- Date, time and guest selection
- Available / selected / occupied seat states
- Login + signup UI
- Frontend demo authentication with localStorage
- Booking history and cancellation
- Booking confirmation screen
- No backend required

## Run
```bash
npm install
npm run dev
```

The app intentionally uses localStorage for demo auth and bookings. Replace the Unsplash image URLs with your own café photography if desired.
